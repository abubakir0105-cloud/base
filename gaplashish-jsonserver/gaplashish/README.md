# Gaplashish + Terminal (json-server)

## 1-noutbuk (server)
1. Node.js o'rnating (https://nodejs.org)
2. Papkada:  npm install  &&  npm start
3. IP manzilni toping:  Windows: `ipconfig`  |  Mac/Linux: `ifconfig` yoki `ip a`
   (masalan 192.168.1.15)

## 2-noutbuk
Bir xil Wi-Fi/tarmoqda brauzerda oching:  http://192.168.1.15:3000
(1-noutbuk ham http://localhost:3000 ni ocha oladi)

Muammo bo'lsa: 1-noutbukda 3000-port Firewall'da ruxsat etilganini tekshiring.
